📱 AR Drawing V5
Hướng dẫn lấy APK không cần Android Studio

1Tạo tài khoản GitHub miễn phí

Vào github.com → Sign up

Điền: email, mật khẩu, username → Xác nhận email là xong.

2Tạo repository mới

  1. Nhấn nút + góc trên phải → New repository
  2. Repository name: ar-drawing
  3. Chọn Public
  4. Nhấn Create repository

3Upload toàn bộ file project

  1. Trên trang repository mới → tìm link "uploading an existing file"
  2. Mở thư mục ardrawing_v5 trên máy tính
  3. Chọn tất cả (Ctrl+A hoặc Cmd+A) → kéo thả vào trình duyệt
  4. Chờ upload xong → Cuộn xuống → nhấn Commit changes
⚠️ Quan trọng: phải upload CẢ thư mục con (.github, app, gradle, ...) — không chỉ file lẻ!

4Chờ GitHub tự động build (~5 phút)

  1. Vào tab Actions trên trang GitHub
  2. Thấy workflow "🏗️ Build AR Drawing APK" đang chạy
  3. Chờ biểu tượng chuyển từ ⚙️ sang ✅
💡 Nếu không thấy workflow tự chạy: Nhấn Actions → "Build AR Drawing APK" → nút "Run workflow" màu xanh

5Tải APK về điện thoại

  1. Nhấn vào workflow run đã hoàn thành ✅
  2. Cuộn xuống mục Artifacts
  3. Nhấn ARDrawing-V5-debug-apk → tải file ZIP
  4. Giải nén → lấy file app-debug.apk
  5. Chuyển file sang điện thoại → Cài đặt

📲 Cài APK lên Android

Bật cài từ nguồn không rõ:
Cài đặt → Ứng dụng → (tìm trình duyệt/Files bạn dùng) → Cho phép cài ứng dụng

Hoặc: Cài đặt → Bảo mật → Cài từ nguồn không rõ → Bật
